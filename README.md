## Description

This project serves as the scraper backend for managing and orchestrating job execution. It provides APIs and logic to queue, schedule, and monitor jobs.

## Project setup

# Git clone
```
$ git clone <git_link>
```

# Git commands
```
$ git switch developer
$ git pull origin developer
$ git checkout -b new-branch
```
Make changes to your code
```
$ git add .
$ git commit -m "Your fancy commit message"
$ git switch developer
$ git pull origin developer
$ git switch new-branch
$ git rebase developer
$ git push origin new-branch
```
# NPM Setup

```bash
$ npm install --legacy-per-deps
```

## Compile and run the project

```bash
# development(don't follow)
$ npm run start

# watch mode/development
$ npm run dev
```
